iOS Safari 録画ガイド

iOS Safari（iPhone / iPad）で本アプリを利用する際の注意事項と手順です：

1. ブラウザでの画面録画 (`getDisplayMedia`)

iOS 13+ のSafariでは一部制限付きで動作しますが、OSのセキュリティ仕様により画面全体の共有ダイアログが表示される場合と、許可されない場合があります。

2. iOS標準のコントロールセンター録画（推奨）

iPhone全体（他アプリ含む）の画面を録画したい場合は、iOS標準機能のご利用が最も確実です：

  1. 「設定」＞「コントロールセンター」を開く
  2. 「画面収録」を追加
  3. 画面右上からスワイプダウンし、二重丸の録画ボタンをタップ

3. 本アプリでの動画保存 (Web Share)

録画終了後、「共有 / 保存 (iOS)」ボタンを押して「ビデオを保存」を選択すると、iOSの「写真」アプリへ直接保存できます。
