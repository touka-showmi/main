このプレビューの見方と限界

スマートフォン一覧は、日本国内で販売・流通する主要ブランドの2025～2026年の現行・直近モデルを中心とした代表機種カタログです。全メーカーの歴代全型番を意味するものではありません。画面解像度はメーカー公表値を優先し、メーカーがFHD+等の表記のみで詳細画素数を示していない場合は、代表的な近似値として登録し、機種詳細欄で未確認・推定であることを表示します。

機種ごとのパネル解像度とCSSビューポートを使って、端末画面の形とレスポンシブ幅を再現します。上部の端末模型倍率100%はプレビュー領域に収める最大フィットであり、実寸のインチ比を保つ縮尺ではありません。そのため、通常端末同士の物理的な大きさを厳密に相互比較する用途には使えません。Galaxy Z Flip8、iPhone Duo、Pixel 11 Pro Fold、OPPO Find N6、motorola razr foldは、閉じた状態と展開状態で同じ物理縮尺を使い、折りたたみ前後の外形変化を確認できるようにしています。折りたたみ端末は各状態を独立した端末候補として登録しているため、端末送りでも両方を順番に確認できます。ただし、実機OS・ブラウザーUI・ステータスバー・ジェスチャー領域を完全にエミュレートするものではありません。

赤はノッチ・ホーム操作・端ジェスチャーなどと重要要素が干渉しやすい領域、黄色はボタンなどを端に密着させないための余白目安です。折りたたみ画面の中央線はヒンジ位置の目安であり、実機の折り目幅を実寸再現するものではありません。折り目線の方向は、製品ごとの折りたたみ時／展開時の幅・高さの公表値から算出し、展開時の本体アスペクト比を基準に画面回転へ追従させます。背景や動画プレビューなど、端まで表示してよいコンテンツは赤・黄色の領域にも表示できます。

スマートウォッチはケースとバンドを描き、角丸四角形／円形の画面形状を反映します。黄色の輪郭は画面端で情報が切れないようにする安全余白の目安です。Apple WatchのwatchOSアプリは通常のSafari／Chrome向けWebページと同じ実行環境ではなく、Galaxy／Pixel等のWear OSでも利用できるブラウザーやCSS viewportは機種・OS・ブラウザーに依存します。ここで読み込むHTMLはCSS幅のレスポンシブ確認用であり、watchOSアプリやWear OSアプリそのものの画面エミュレーションではありません。

上部のHTML読み込み欄から .html / .htm を選ぶと、端末画面内のiframeで表示します。端末送りボタンで機種を連続して切り替え、縦横や折りたたみ状態ごとのレイアウトを確認できます。iframeはsandboxで分離しており、スクリプト・フォーム等は許可しますが、親ページと同じオリジンへのアクセスは制限します。localStorage、Cookie、Service Workerなどは利用できない場合があります。外部ファイルを相対パスで参照するHTMLは正しく表示できない場合があるため、CSS・画像・JavaScriptをHTMLに内包した単一ファイルが適しています。

iframeのページ倍率は標準の100%（1 CSS pxを1 CSS pxとしてレイアウト）を基本にします。折りたたみGalaxyのCSS表示領域はAndroid実機のWindowMetrics／表示密度の測定値に置き換えました。追加したAndroidスマートフォンのCSS表示領域は、パネル解像度を標準的な3x密度で換算した参考値を基本とし、個別の実機WindowMetricsを確認できていない値は機種詳細欄に推定と明記しています。Lenovo Legion TabはメーカーがAndroid論理密度を公開していないため、408PPIに近い420dpiを仮定した推定値です。選択端末ごとのCSSビューポート幅・高さをiframe自体に設定し、画面模型に収めるための縮小はiframeの外側ラッパーだけに適用します。そのため、外側のプレビュー表示倍率を変更しても、ページ内のCSSメディアクエリーや window.innerWidth は端末の推定CSSビューポートを基準に維持されます。HTMLにviewport metaがない場合は width=device-width, initial-scale=1 を補います。既存のviewport metaは尊重します。なお、通常のHTMLだけでは選択した実機の devicePixelRatio、OS文字サイズ、ブラウザーUI、GPU描画密度を完全にはエミュレートできません。iframeから報告するDPRは、このプレビューを開いている実行環境の値です。例えば、PC上で開けばPCのDPR、iPhone上で開けばそのiPhoneのDPRが表示され、選択中の端末モデルに応じて切り替わる値ではありません。DPR依存の canvas、srcset、resolution メディアクエリー、タッチ／ポインター特性は実機または開発者ツールのデバイスエミュレーションで確認してください。
